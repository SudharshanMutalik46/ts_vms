# Security Policy

## Reporting a vulnerability

Please use GitHub's private vulnerability-reporting option for this repository when it is available. Do not include real credentials, private camera URLs, recordings, access tokens, or personal data in a public issue.

Include the affected component, reproduction steps using test data, expected impact, and any suggested mitigation.

## Development safety

- Use non-production cameras and accounts.
- Store configuration in ignored environment files.
- Rotate any credential that is accidentally committed.
- Do not use this development project as a production security control without a separate security review.
